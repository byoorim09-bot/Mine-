# 영앤클래식

날씨·기분·상황에 맞춘 중년 남녀 풀 코디 추천 웹앱입니다.
GitHub Pages로 서비스되며, 모든 화면은 `index.html` 한 파일에 들어 있습니다.

- 성별·날씨·기분·상황 선택 → **큐레이션된 실착장 코디 세트 3가지** 추천
- 코디는 무작위 조합이 아니라 **`CURATED_LOOKS` 42세트**(남/여 × 날씨 4구간 × 5~6세트)에서 고릅니다.
  카드의 옷 5가지(아우터·상의·하의·신발·소품)와 착장 사진(`looks/set_XX.jpg`)이 항상 1:1로 맞습니다.
- 아이템 96종(의류·트레이닝복 포함) · 아이템 사진 `items/` (실사 스튜디오 컷, 종류-색상별)
- 가격은 `3만~`·`5만~` 같은 원대 표기, 합계 금액은 표시하지 않습니다
- 아이템·찜한 옷 카드마다 `네이버쇼핑에서 최저가 보기`(네이버 쇼핑 커넥트) · `쿠팡에서 최저가 보기`(쿠팡 파트너스) 연결
  — 전 품목 96/96 제휴 링크 연결 완료, 결제·주문 화면은 두지 않습니다
- `찜한 옷` 목록(이 브라우저에만 저장), 나만의 코디북 저장, 화면 글자 크기 조절
